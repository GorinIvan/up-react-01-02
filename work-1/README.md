# Практическая работа №1. Карточки товаров

Откройте папку в VS Code. Нужен Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. В `src/App.jsx` лежит массив товаров. Компонент `ProductCard` получает название, цену и картинку-заглушку через props. У каждой карточки свой счётчик на `useState`.
