# Sneaker Store

Практическая работа №4. Интернет-магазин кроссовок на React, Express и SQLite.

## Как запустить

Откройте папку `work-4` в VS Code. Нужен Node.js 22.13 или новее.

```sh
npm ci
npm run build
npm start
```

Откройте [http://127.0.0.1:3002](http://127.0.0.1:3002). SQLite создаст файл `backend/store.sqlite` при первом запуске.

Для разработки запустите `npm run dev:api` в первом терминале и `npm run dev` во втором. Откройте [http://127.0.0.1:5176](http://127.0.0.1:5176).

## Учебные аккаунты

| Роль | Email | Пароль |
| --- | --- | --- |
| Пользователь | client@sneaker.test | Client12345 |
| Администратор | admin@sneaker.test | Admin12345 |

Для проверки можно зарегистрировать отдельного пользователя. В каталоге есть поиск, категории, фильтр по цене, сортировка и смена темы. После выбора размера и количества нажмите «В корзину». Корзина хранится в базе, а купон START10 учебного покупателя применяется автоматически.

В корзине заполните адрес и дату доставки. Заказ появится в личном кабинете. Там же можно поменять данные и пароль. Отзывы открываются по названию кроссовок. Для публикации нужно войти в аккаунт.

В разделе «Управление» администратор добавляет, меняет и удаляет товары, категории, купоны, учётные записи покупателей, отзывы, строки корзин и заказы. Для удаления категории сначала перенесите её товары в другую категорию. Заказ администратор может оформить из корзины выбранного покупателя.

## Восстановление пароля

В форме входа нажмите «Забыли пароль?» и введите email. В учебном режиме письмо появится в `backend/mailbox.log`. Откройте последнюю ссылку для указанного email в том же браузере, где запущен магазин. Ссылка одноразовая и действует 30 минут. Для отправки через почтовый сервер укажите `SMTP_URL`, `MAIL_FROM` и `APP_URL` в собственном `.env`. Пример есть в [.env.example](.env.example).

## Как устроен проект

- `src/` содержит функциональные компоненты React. `useState` хранит состояние интерфейса, `useEffect` загружает данные и сохраняет тему.
- `backend/schema.sql` содержит таблицы. SQL-запросы с JOIN связывают товары, категории, авторов, корзины, купоны и заказы.
- Браузер работает через API. Для товаров используются артикулы, для заказов их номера, а внутренние числовые ключи остаются в базе.
- Пароли хранятся в виде хешей, а вход подтверждается сессионной cookie. Сервер проверяет пользователя и роль на закрытых маршрутах.
- Сервер записывает заказ, цены на момент покупки и очистку корзины в одной транзакции.

Иллюстрации учебных моделей в [public/shoes](public/shoes) созданы с помощью ImageGen как сетка из шести фотореалистичных кроссовок сбоку на светло-сером студийном фоне, без логотипов.
