# Практическая работа №2. Каталог, корзина и тема

Нужен Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:5174. Добавление товара открывает корзину через `useNavigate`. При повторном добавлении растёт количество. Кнопка «Удалить» убирает строку. Корзина и тема хранятся в `ShopContext` и доступны на всех страницах до перезагрузки.

Для учебного входа используйте `student@example.test` и `student123`. Данные проверяются в React. После успешного входа открывается `/dashboard`.

Пример из лекции: [React for Students](https://github.com/Pberom/React_for_Students).
