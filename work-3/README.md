# Практическая работа №3. Салон красоты

Нужен Node.js 22.13 или новее. Установите зависимости в папке проекта.

```sh
npm ci
```

В первом терминале запустите API командой `npm run dev:api`. Во втором запустите React командой `npm run dev`. Откройте http://127.0.0.1:5175. Vite передаёт запросы с путём `/api` на порт 3001. Чтобы использовать другой порт, укажите его в `.env` (пример в `.env.example`).

## Учебные аккаунты

| Роль | Email | Пароль |
| --- | --- | --- |
| Клиент | client@salon.test | client123 |
| Клиент | guest@salon.test | guest123 |
| Администратор | admin@salon.test | admin123 |

В каталоге категории отмечаются галочками. Услугу можно добавить несколько раз. В корзине видны количество, сумма строки и общий итог. Общая скидка применяется к цене услуги, затем к сумме корзины применяется купон клиента. Начальный каталог содержит 10 услуг, из них 3 со скидкой. Администратор меняет проценты, назначает один купон клиенту и добавляет категории. Для просмотра нового купона войдите в аккаунт клиента заново.

## Данные и API

SQLite создаёт файл `backend/salon.sqlite` при первом запуске. Структура таблиц находится в `backend/schema.sql`, начальные данные в `backend/seed.sql`. Таблицы `Appointments` и `Payments` описывают записи и платежи. Интерфейс реализует каталог, корзину, вход и настройки администратора.

В `backend/server.js` находятся маршруты Express. В `src/api.js` находится функция запросов `fetch`. Структура взята по примерам [React for Students](https://github.com/Pberom/React_for_Students/tree/main/my-api) и [ReactSalon](https://github.com/lucypyank1/ReactSalon). API работает локально вместе с приложением.
