# Практическая работа №3. Магазин видеоигр

Нужен Node.js 22.13 или новее. Установите зависимости в папке проекта.

```sh
npm ci
```

В первом терминале запустите API командой `npm run dev:api`. Во втором запустите React командой `npm run dev`. Откройте http://127.0.0.1:5175. Vite передаёт запросы с путём `/api` на порт 3001. Чтобы использовать другой порт, укажите его в `.env` (пример в `.env.example`).

## Учебные аккаунты

| Роль | Email | Пароль |
| --- | --- | --- |
| Клиент | client@games.test | client123 |
| Клиент | guest@games.test | guest123 |
| Администратор | admin@games.test | admin123 |

В каталоге жанры отмечаются галочками. Игру можно добавить несколько раз. В корзине видны количество, сумма строки и общий итог. Общая скидка применяется к цене игры, затем к сумме корзины применяется купон клиента. В начальном каталоге 10 популярных игр из [статистики Steam](https://store.steampowered.com/stats/stats/), из них 3 со скидкой. Цены учебные. Администратор меняет проценты, назначает один купон клиенту и добавляет жанры. Для просмотра нового купона войдите в аккаунт клиента заново.

## Данные и API

SQLite создаёт файл `backend/games.sqlite` при первом запуске. Структура таблиц находится в `backend/schema.sql`, начальные данные в `backend/seed.sql`. Игры хранятся в `Services`, жанры — в `Categories`. Таблицы `Appointments` и `Payments` сохранены по заданию.

В `backend/server.js` находятся маршруты Express. В `src/api.js` находится функция запросов `fetch`. Структура взята по примерам [React for Students](https://github.com/Pberom/React_for_Students/tree/main/my-api) и [ReactSalon](https://github.com/lucypyank1/ReactSalon). API работает локально вместе с приложением.

Обложки взяты со страниц игр в [Steam](https://store.steampowered.com/). Права на изображения принадлежат их правообладателям.
